Accuracy · benchmark v3 (%)

Typed decisions

Decisions, not arithmetic.

On benchmark v2, about three quarters of the gap between Jev and reasoning models came from multi-step calculation: time-zone conversion, cent rounding, stock sums. Benchmark v3 hands over those quantities already computed and tests the decision on top: 200 scenarios, one combined decision-and-reason question each, 200 calls per model. Typed decision services, local models and thinking models answer the same prompts, at one sample and concurrency 1. v3 is the default system1 suite; v2 remains as a reference.

Dataset v3

200 scenarios. 200 calls.

Ten families of 20 scenarios. Facts arrive in prose: customer emails, chat transcripts, staff notes. Models must tell claims from confirmations, notice when a case cannot be decided yet, and ignore instructions planted in untrusted text. Every question has listed options, and each answer names the decision and its reason together. Six families state each case twice in different wording; a model must answer both versions correctly.

One sample per question gives 200 responses per model. With 200 items a 95% interval is about ±5 points near 85%, so smaller margins are noise. Paraphrase pairs are correlated, so intervals describe scored attempts. Read the dataset design →

Reproduce it

Run benchmark v3 on your endpoint.

One endpoint, any backend: configs/s1_gateway.py on :8123. Swap the backend by environment variable; the application never sees the change.

./bench run --suite system1 --samples 1 --concurrency 1
