Typed decisions

Same contract. Different engines.

Each model takes application state plus a question and returns a typed pick with probabilities — no free text to parse. Local and hosted backends sit behind the same standard s1 gateway, so swapping one is an env change, not an application change. Jev is the historical baseline; fresh runs put both Cloudflare Clef models at 98.0% (96/98), with the same error_log/q1 misses. Clef-Flash takes 0.69 s/question and fits alongside Qwen; the 27B Clef takes 1.93 s and needed Qwen vLLM paused to fit. Flash remains the practical Clef choice, including its measured 16/16 phishing result. These small suites are near saturation, not proof of a perfect model.
